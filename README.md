# تطبيق أسعار العملات مقابل الجنيه المصري (EGP)

تطبيق أندرويد مبني بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** مع دعم كامل للغة العربية (RTL).

## المميزات
- جلب أسعار الصرف الحية مقابل الجنيه المصري عبر [ExchangeRate-API Open Access](https://www.exchangerate-api.com/docs/free) بدون الحاجة إلى مفتاح API.
- تخزين مؤقت (Cache) لمدة ساعة لتفادي تجاوز حدود الطلبات.
- محول عملات سريع مع إمكانية التبديل بين التحويل من العملة الأجنبية إلى الجنيه والعكس.
- بحث فوري باسم العملة أو رمزها (USD, SAR, EUR, AED, KWD...).

## طريقة التشغيل
1. فك ضغط ملف `EgpCurrencyApp.zip`.
2. افتح المجلد في **Android Studio**.
3. انتظر مزامنة Gradle ثم شغّل التطبيق على المحاكي أو هاتف أندرويد (API 24+).
